BWLandEditorGUI

Progetti, file, importazione/esportazione e recupero

L’editor considera il terreno (.lnd) e lo script di inizializzazione LHX (.txt) come componenti correlate dello stesso progetto e salva ciascuna quando contiene modifiche non salvate.

Apertura e salvataggio

  • Apri accetta file .lnd e .txt. Aprendo uno script LHX, il terreno a cui fa riferimento può essere caricato automaticamente se la cartella del gioco è configurata.
  • Salva salva entrambi i componenti modificati. Salva mappa con nome e Salva LHX con nome consentono di scegliere destinazioni distinte.
  • Aprendo un altro progetto o uscendo viene chiesto come gestire le modifiche in sospeso.
  • La finestra iniziale elenca i file .lnd/.txt recenti; il numero massimo è configurabile.

Importazione di una mappa

File → Importa mappa importa blocchi da un’altra mappa senza sostituire quella corrente. Le regioni utilizzate dai dati importati vengono associate alle regioni di destinazione. La finestra supporta corrispondenza automatica, decisioni manuali di associazione/importazione, memorizzazione delle associazioni e cancellazione delle decisioni salvate.

Dopo l’associazione, il terreno importato appare come anteprima nella vista 3D. Spostalo nella posizione desiderata e conferma con Invio; Esc annulla. È possibile richiedere l’allineamento alla griglia.

Importazione di una height map

File → Importa height map legge un PNG, lo converte in terreno e permette poi di posizionare il risultato. Prima dell’importazione puoi:

  • ruotare in senso orario/antiorario oppure riflettere orizzontalmente/verticalmente ;
  • scegliere le regioni normale, dirupo e linea costiera, inclusi i pulsanti per prelevarle dalla mappa;
  • impostare pendenza del dirupo, suono ambientale e allineamento alla griglia;
  • usare la procedura guidata di configurazione delle regioni in un clic.

Esportazione

Esporta height map salva il terreno corrente in PNG. Il pulsante screenshot salva la vista 3D renderizzata.

Salvataggio automatico e recupero

Esistono due protezioni separate. Salvataggio automatico scrive periodicamente i file di lavoro; Autorecovery crea copie temporanee di recupero per le modifiche non salvate a terreno/LHX.

Dopo un’interruzione anomala, le voci di recupero compaiono nella finestra iniziale e possono essere riaperte o rimosse. I file di recupero vengono eliminati automaticamente dopo il normale salvataggio del documento corrispondente.

Questa guida è stata completata a partire dal codice sorgente BWLandEditorGUI fornito. Le diciture dell’interfaccia possono variare in base alla lingua selezionata nell’applicazione.
