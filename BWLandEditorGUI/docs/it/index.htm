Flusso di lavoro rapido

  1. Apri un progetto .lnd o LHX .txt esistente, oppure crea un nuovo progetto.
  2. Definisci o importa materiali e regioni.
  3. Modella il terreno con gli strumenti di scultura/oceano/lago e disegna regioni o suoni ambientali.
  4. Passa alla modalità Posizionamento oggetti per aggiungere e configurare gli oggetti LHX.
  5. Usa la finestra Script LHX per modificare le singole istruzioni, quindi salva sia il terreno sia lo script.
Questa guida è stata completata a partire dal codice sorgente BWLandEditorGUI fornito. Le diciture dell’interfaccia possono variare in base alla lingua selezionata nell’applicazione.
