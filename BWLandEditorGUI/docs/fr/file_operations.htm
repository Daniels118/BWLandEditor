BWLandEditorGUI

Projets, fichiers, import/export et récupération

L’éditeur traite le paysage (.lnd) et le script d’initialisation LHX (.txt) comme deux composants liés d’un même projet et enregistre chacun lorsqu’il contient des modifications non enregistrées.

Ouvrir et enregistrer

  • Ouvrir accepte les fichiers .lnd et .txt. L’ouverture d’un script LHX peut charger automatiquement le paysage référencé si le dossier du jeu est configuré.
  • Enregistrer sauvegarde les deux composants modifiés. Enregistrer la carte sous et Enregistrer le LHX sous permettent de choisir des destinations séparées.
  • L’ouverture d’un autre projet ou la fermeture de l’application affiche une demande concernant les modifications en attente.
  • La fenêtre de démarrage répertorie les fichiers .lnd/.txt récents ; leur nombre maximal est configurable.

Importer une carte

Fichier → Importer une carte importe des blocs depuis un autre paysage sans remplacer le paysage actuel. Les régions utilisées dans les données importées sont associées aux régions de destination. La boîte de dialogue prend en charge la correspondance automatique, les décisions manuelles d’association/importation, la mémorisation des associations et l’effacement des décisions enregistrées.

Après l’association, le terrain importé apparaît en aperçu dans la vue 3D. Déplacez-le à la position voulue et confirmez avec Entrée ; Échap annule. Un alignement sur la grille peut être demandé.

Importer une height map

Fichier → Importer une height map lit un PNG, le convertit en terrain puis permet de positionner le résultat. Avant l’importation, vous pouvez :

  • faire pivoter dans le sens horaire/antihoraire ou réfléchir horizontalement/verticalement ;
  • choisir les régions normale, falaise et littoral, y compris via les boutons de prélèvement sur la carte ;
  • définir la pente de falaise, le son d’ambiance et l’alignement sur la grille ;
  • utiliser l’assistant de configuration des régions en un clic.

Export

Exporter la height map écrit le terrain actuel dans un PNG. Le bouton de capture enregistre la vue 3D rendue.

Enregistrement automatique et récupération

Deux protections distinctes existent. Enregistrement automatique écrit périodiquement les fichiers de travail ; Récupération automatique crée des copies temporaires des modifications non enregistrées du paysage/LHX.

Après une interruption anormale, les entrées de récupération apparaissent dans la fenêtre de démarrage et peuvent être rouvertes ou supprimées. Les fichiers de récupération sont supprimés automatiquement après l’enregistrement normal du document correspondant.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
