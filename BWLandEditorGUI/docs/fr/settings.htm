Préférences utilisateur

Ouvrez les préférences via Édition → Préférences…. La fenêtre Paramètres permet la recherche et regroupe les options par catégorie.

CatégorieParamètreSignification / valeur par défaut
Interface utilisateurLangueLangue système/par défaut au premier démarrage ; sélectionnable parmi les traductions disponibles.
ÉditionEnregistrement automatiqueActive les enregistrements normaux périodiques.
ÉditionIntervalle d’enregistrement automatique1–60 minutes ; valeur par défaut 10.
ÉditionNombre maximal d’annulations1–1000 modifications ; valeur par défaut 50.
IntégrationsPort HTTP8086 par défaut.
IntégrationsPort de l’éditeur externe8085 par défaut.
JeuDossier du jeuDossier utilisé pour localiser les ressources de Black & White et les paysages référencés par les scripts LHX.
Vue 3DAttributs des cellulesDésactivé / Propriétés / Sons.
Vue 3DGrilleAucune / Seulement sur l’eau / Partout.
Vue 3DAfficher les cellulesActive/désactive la visualisation au niveau des cellules.
Vue 3DObjetsAucun / Tous / Construits / Planifiés.
Vue 3DObjets virtuelsAffiche les objets auxiliaires/virtuels.
Vue 3DLiensAffiche les liens de relation entre objets.
Vue 3DBoussoleAffiche la boussole.
Vue 3DEmpêcher la caméra de passer sous terreContraint l’orbite pour éviter la pénétration du terrain ou une occlusion trop proche.
Vue 3DMettre en évidence la région sélectionnéeOmbrage les régions non sélectionnées.
Vue 3DContourner la région sélectionnéeDessine le contour de la région sélectionnée.
DiversNombre maximal de fichiers récents0–15 ; valeur par défaut 5.
DiversStockage des métadonnéesIntégré ou externe.
DiversQualité d’enregistrement des images0,2–1,0 ; valeur par défaut 0,8.
DiversRécupération automatiqueActive les copies temporaires de récupération.
DiversIntervalle de récupération automatique1–10 minutes ; valeur par défaut 1.
DiversOuverture automatique de la consoleAffiche automatiquement la console lorsque cela s’applique.
Les paramètres sont conservés dans le magasin de préférences LibGDX de l’application. Les options liées à la vue mettent immédiatement à jour la vue 3D.
Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
