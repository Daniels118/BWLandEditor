Placement et modification des objets

Le mode Placement d’objets modifie les instructions LHX de création d’objets au moyen d’un flux 3D tout en maintenant le script synchronisé.

Catalogue et glisser-déposer

Passez à Placement d’objets. La fenêtre Catalogue affiche des aperçus de modèles recherchables chargés depuis les ressources du jeu. Faites glisser un élément du catalogue sur un terrain valide ; les dépôts invalides ou hors limites sont signalés et refusés.

Valeurs automatiques lors de la création

Les nouvelles instructions reçoivent leur type d’objet, leur position, leur âge et un nouvel ID lorsque cela est nécessaire. Selon la commande, l’éditeur tente également de déduire les relations :

  • le joueur depuis la ville la plus proche ;
  • la ville depuis une ville voisine, lorsque la commande prend en charge cette association ;
  • le troupeau depuis un troupeau voisin lorsque le point se trouve dans son rayon ;
  • la forêt depuis une forêt voisine ;
  • le domicile du villageois depuis l’habitation libre compatible la plus proche.

Sélection et déplacement des objets

L’outil Pointeur sélectionne les objets. Ctrl-clic inverse la sélection d’un objet. Un glisser déplace les objets sélectionnés en groupe ; commencer le glisser en maintenant Ctrl duplique d’abord les instructions sélectionnées.

L’outil de sélection polygonale prend en charge Nouvelle/Ajouter/Soustraire/Intersection. Un clic droit sur les objets ouvre des commandes permettant d’affiner/étendre la sélection, de sélectionner parents/frères/enfants/descendants, d’afficher un objet dans la Vue arborescente LHX, ou de copier, couper et supprimer.

Propriétés de l’objet

La fenêtre Propriétés de l’objet est générée à partir du schéma d’arguments de la commande sélectionnée. Elle prend en charge les coordonnées, flottants/entiers, booléens, chaînes et choix d’arguments énumérés. Les contraintes de position/rotation/échelle/âge sont adaptées à la commande. Les ID dupliqués sont signalés.

Des panneaux spécialisés existent pour la croyance de la ville, les plafonds de croyance et les bonus de désirs ; les habitations affichent le nombre d’adultes/enfants et les indicateurs pertinents tels que planifié/mort/inhabitable lorsqu’ils sont pris en charge.

Vue arborescente LHX

L’arborescence fournit une hiérarchie recherchable des objets LHX rendus et suit la sélection dans la vue 3D. Les liens parent/enfant correspondent aux relations affichées par la superposition Liens.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
