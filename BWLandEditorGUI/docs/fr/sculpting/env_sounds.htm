Sons d’ambiance

Peindre les sons écrit l’énumération de son d’ambiance stockée dans les cellules du terrain. Son activation bascule temporairement la superposition des attributs de cellules vers la visualisation des sons.

Pinceau et filtres

Le pinceau prend en charge les formes Cercle/Triangle, la taille, les proportions et la rotation. Choisissez le son cible, puis limitez la peinture selon :

  • sur la terre ;
  • sur le littoral ;
  • près du littoral ;
  • sur l’eau ;
  • la plage de pente ;
  • la plage d’altitude.

Icônes de sons incluses dans l’interface

Océan Côte Lac Rivière Vagues lentes Vagues rapides Splash Vent Oiseaux Forêt Jungle Désert.

La liste exacte affichée par l’application provient de l’énumération des sons de cellules LND disponible à l’exécution.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
