Définition des matériaux

L’Éditeur de matériaux gère les ressources de texture utilisées par les régions du terrain.

Ouvrir

Utilisez Outils → Éditeur de matériaux. Les matériaux sont affichés sous forme de miniatures ; les matériaux inutilisés ont des libellés atténués.

Opérations

ActionDescription
Type de matériau de terrainAttribue la classification de terrain au matériau sélectionné.
Importer un matériauImporte une texture PNG comme ressource de matériau.
Modifier la textureOuvre l’éditeur de texture avec aperçu en direct et commandes Appliquer/Annuler.
DupliquerClone le matériau.
Remplacer les occurrencesRemplace toutes les références au matériau sélectionné par un autre matériau.
ExporterÉcrit le matériau sélectionné dans un PNG.
SupprimerDisponible uniquement lorsque le matériau peut être supprimé sans risque.

La même fenêtre peut être ouverte en mode sélection par d’autres outils, par exemple l’Éditeur de régions, afin de choisir un matériau plutôt que de modifier la liste.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
