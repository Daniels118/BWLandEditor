Définition des régions

Une région définit la façon dont les matériaux du terrain changent selon l’altitude et le noise et constitue la principale classification de surface stockée dans les cellules.

Liste des régions

Ouvrez Outils → Éditeur de régions. La liste affiche une miniature, un nom et le pourcentage approximatif de cellules utilisant chaque région. L’éditeur propose les commandes Ajouter et Importer.

Menu contextuel de région

Remplacer les occurrencesRéaffecte les cellules utilisant cette région à une autre région de destination.
Copier depuis / DupliquerCopie le type de terrain, la carte des matériaux et le nom depuis une autre région, ou clone la région sélectionnée.
Importer depuis / ExporterLit depuis .lndc ou un autre .lnd ; exporte vers .lndc.
Définir le type de terrain / RenommerModifie les métadonnées.
Permuter / SupprimerDisponible uniquement lorsque la région concernée n’est pas utilisée, afin de protéger les index de cellules actifs.

Mélangeur de matériaux

Le mélangeur représente la pile de matériaux de la région en fonction de l’altitude. Faites glisser verticalement les points de contrôle pour déplacer les transitions. Un clic droit permet de scinder une transition vers le haut ou le bas, d’insérer ou de changer un matériau, ou d’en supprimer un lorsque la disposition actuelle le permet.

Noise et aperçu

L’aperçu peut afficher la contribution de la noise map. Modifier… ouvre l’Éditeur de noise map. L’Éditeur de régions peut également ombrer les régions non sélectionnées et dessiner le contour de la région sélectionnée dans la vue 3D principale.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
