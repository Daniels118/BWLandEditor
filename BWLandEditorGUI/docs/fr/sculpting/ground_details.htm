Détails du terrain et cartes auxiliaires

Le code source fourni expose plusieurs ressources auxiliaires du terrain et outils de maintenance plutôt qu’un unique pinceau « détails du sol ».

Noise map

Outils → Éditeur de noise map prévisualise la noise map actuelle et permet l’import PNG, l’export PNG et l’inversion. L’Éditeur de régions peut superposer cette carte dans l’aperçu de la région.

Bump map du littoral

Outils → Éditeur de bump map du littoral propose le même flux import/export/inversion pour la ressource bump du littoral.

Visualiseurs de textures

Le menu Outils peut ouvrir des visualiseurs en lecture seule pour la small bump texture et la texture du ciel.

Ombres

Édition → Mettre à jour les ombres recalcule les informations d’ombre du terrain. Les opérations de sculpture mettent également à jour les ombres des blocs modifiés par le trait.

Le code source fourni ne contient pas d’outil séparé de peinture des détails du terrain ; cette page documente les ressources de détail actuellement implémentées.
Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
