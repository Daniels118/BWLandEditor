Scripts LHX

La fenêtre Script LHX est un éditeur ligne par ligne directement lié à la liste actuelle d’instructions LHX. La modification d’une instruction met à jour la représentation 3D de l’objet, et la sélection d’un objet rendu peut révéler sa ligne de script.

Édition

  • Chaque ligne est analysée comme une instruction LHX. Les commandes valides, les commentaires et les instructions invalides utilisent des styles différents.
  • Entrée au début/à la fin d’une ligne insère une nouvelle instruction avant/après.
  • La suppression d’une ligne vide avec Retour arrière ou Suppr supprime cette instruction.
  • Les touches fléchées peuvent passer entre les lignes adjacentes aux limites de ligne ; Page précédente/suivante se déplace par pages visibles.
  • Ctrl+Home/End va à la première/dernière instruction.
  • Ctrl+Espace ouvre la complétion contextuelle des commandes/arguments.

Recherche

Le champ de recherche trouve du texte dans le script avec les commandes précédent/suivant et reprend la recherche au début/à la fin lorsque nécessaire.

Repérage de la position

Le survol d’une commande possédant une position affiche un marqueur temporaire dans la vue 3D. La sélection est synchronisée dans les deux sens entre le script et les objets rendus.

Attributs de la carte

Édition → Paramètres de la carte ouvre un éditeur structuré des propriétés de carte au niveau du script. Le code source fourni comprend :

  • des paramètres généraux tels que version, numéro de carte/chemin du paysage, multiplicateurs d’influence ville/joueur, durée du jour et rapports jour/nuit/aube-crépuscule ;
  • la configuration des joueurs contrôlés par l’ordinateur ;
  • les propriétés d’équilibrage ;
  • les probabilités des miracles firefly ;
  • les paramètres d’escarmouche, y compris le nombre de joueurs et les messages de début/de jeu.

Assistant caméra

Le mode Script ouvre Informations sur la caméra, qui expose la position actuelle et le point regardé et peut générer/copier des commandes set/move de caméra à utiliser dans les scripts.

Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
