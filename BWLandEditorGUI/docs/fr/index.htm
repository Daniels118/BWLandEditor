Flux de travail rapide

  1. Ouvrez un projet .lnd ou LHX .txt existant, ou créez un nouveau projet.
  2. Définissez ou importez des matériaux et des régions.
  3. Modelez le terrain avec les outils sculpture/océan/lac et peignez les régions ou les sons d’ambiance.
  4. Passez au Placement d’objets pour ajouter et configurer les objets LHX.
  5. Utilisez la fenêtre Script LHX pour modifier les instructions, puis enregistrez le terrain et le script.
Ce guide a été complété à partir du code source BWLandEditorGUI fourni. Les libellés de l’interface peuvent varier selon la langue sélectionnée dans l’application.
