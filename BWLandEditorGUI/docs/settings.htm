User preferences

Open preferences from Edit → Settings…. The Settings window is searchable and groups options by category.

CategorySettingMeaning / default
UILanguageSystem/default language at first run; selectable from available translations.
EditingAutosaveEnable periodic normal saves.
EditingAutosave interval1–60 minutes; default 10.
EditingMaximum undo1–1000 edits; default 50.
IntegrationsHTTP portDefault 8086.
IntegrationsExternal editor portDefault 8085.
GameGame directoryFolder used to locate Black & White resources and landscapes referenced by LHX scripts.
3D viewCell attributesOff / Properties / Sounds.
3D viewGridNone / Sea / Everywhere.
3D viewShow cellsToggles cell-level visualization.
3D viewObjectsOff / All / Built / Planned.
3D viewVirtual objectsShow helper/virtual objects.
3D viewLinksShow object relationship links.
3D viewCompassShow the compass.
3D viewPrevent camera undergroundConstrains orbiting to avoid terrain penetration/close occlusion.
3D viewHighlight selected countryShade non-selected countries.
3D viewOutline selected countryDraw selected-country outline.
MiscMaximum recent files0–15; default 5.
MiscMetadata storeEmbedded or External.
MiscImage save quality0.2–1.0; default 0.8.
MiscAuto-recoveryEnable temporary recovery copies.
MiscAuto-recovery interval1–10 minutes; default 1.
MiscConsole popupShow console automatically when applicable.
Settings are persisted in the application's LibGDX preferences store. View-related options update the 3D viewport immediately.
This guide was completed from the supplied BWLandEditorGUI source code. UI wording can vary with the selected application language.
