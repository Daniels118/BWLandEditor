BWLandEditorGUI

User interface

The main screen combines a central 3D viewport, a menu bar, a general toolbar, a mode-specific toolbar and dockable utility windows.

Main toolbar

ButtonPurpose
New / Open / SaveCreate a project, open .lnd/.txt, or save all modified project components.
Undo / RedoMove through the edit history. The menu and tooltips include the current edit description.
Copy / Cut / Paste / DeleteOperate on the current cell or object selection. Pasted terrain is positioned interactively; pasted objects are centered around the current camera pivot.
GridCycles grid display: none, sea only, everywhere.
Cell attributesCycles cell overlays: off, properties, sounds.
ObjectsCycles object visibility: off, all, built, planned.
Virtual objectsShows/hides helper or virtual object representations.
LinksShows/hides object relationship links.
CompassShows/hides the 3D compass.
PointerSelect and drag objects directly in the viewport.
SelectionPolygon selection for landscape cells or objects, depending on the current edit mode.
Orbit / PanCamera navigation tools.
Measure / Pick coordinateMeasure distance between points or read/pick a world coordinate.
ScreenshotRenders the 3D view to an image and asks where to save it.

Edit modes

ButtonModeBehavior
SculptEnables terrain editing and the sculpt/ocean/lake/country/sound toolbar.
FootpathShows footpaths. In the supplied source the dedicated footpath toolbar currently contains no editing commands.
Object PlacementOpens the Catalog and LHX Tree panels and makes the Object Attributes window available.
ScriptScript-oriented mode; the Camera Info window is shown automatically. Script editing itself is performed in the LHX Script window.

Selection modes

Clicking opens four selection operations:

NewReplace the current selection.
AddAdd the polygon contents to the selection.
SubtractRemove the polygon contents.
IntersectKeep only the overlap with the existing selection.

Viewport controls

  • Mouse wheel: zoom.
  • Right-drag: orbit; middle-drag or Space+left-drag: pan.
  • With the Orbit/Pan tools active, left-drag performs that camera action.
  • Q/E rotate yaw, R/F pitch, W/A/S/D pan, numeric keypad +/- zoom.
  • Ctrl+Numpad 0 resets the view; Ctrl+Numpad 5 switches to top view; Ctrl+G flies to a coordinate.

Status bar and windows

The status bar shows context messages, cursor XYZ coordinates, used/max landscape blocks and Java heap usage. Dockable windows include Block Inspector, Object Attributes, Catalog, LHX Tree, LHX Script, Camera Info, Edit History and Console.
