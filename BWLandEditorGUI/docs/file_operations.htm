Projects, files, import/export and recovery

The editor treats the landscape (.lnd) and the LHX initialization script (.txt) as related project components and saves either one when it has unsaved changes.

Open and save

  • Open accepts .lnd and .txt. Opening an LHX script can automatically load its referenced landscape when the game directory is configured.
  • Save saves both modified components. Save Landscape As and Save LHX As choose individual destinations.
  • Opening another project or exiting prompts about pending changes.
  • The start window lists recent .lnd/.txt files; the maximum count is configurable.

Import landscape

File → Import Landscape imports blocks from another landscape without replacing the current one. Countries used by the imported data are mapped to destination countries. The dialog supports automatic matching, manual map/import decisions, remembering mappings and clearing stored decisions.

After mapping, the imported land appears as a preview in the 3D view. Move it to the target position and confirm with Enter; Esc cancels. Grid alignment can be requested.

Import height map

File → Import Height Map reads a PNG, converts it into terrain and then lets you position the generated land. Before import you can:

  • rotate clockwise/counter-clockwise or reflect horizontally/vertically ;
  • choose normal, cliff and coastline countries, including pick-from-map buttons;
  • set cliff slope, ambient sound and grid alignment;
  • use the one-click country configuration wizard.

Export

Export Height Map writes the current terrain as PNG. The screenshot button saves the rendered 3D viewport.

Autosave and recovery

Two separate protections exist. Autosave periodically writes the working files; Auto-recovery writes temporary recovery copies for unsaved landscape/LHX changes.

Recovery entries appear in the start window after an abnormal interruption and can be reopened or removed. Recovery files are deleted automatically after the corresponding document is saved normally.
