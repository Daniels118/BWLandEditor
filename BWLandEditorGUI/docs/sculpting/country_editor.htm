Defining countries

A country defines how terrain materials change with elevation/noise and is the main surface classification stored in landscape cells.

Country list

Open Tools → Country Editor. The list shows a thumbnail, name and approximate percentage of cells using each country. The editor provides Add and Import controls.

Country context menu

Replace occurrencesReassigns cells using this country to another destination country.
Copy from / DuplicateCopies terrain type, material map and name from another country, or clones the selected country.
Import from / ExportReads from .lndc or another .lnd; exports to .lndc.
Set terrain type / RenameEdits metadata.
Swap / RemoveOnly enabled when the involved country is not in use, protecting live cell indexes.

Material mixer

The mixer represents the country's material stack over elevation. Drag control points vertically to move transitions. Right-click the mixer to split a transition up/down, insert a material, change a material or remove a material when the current layout allows it.

Noise and preview

The preview can display the noise contribution. Change Noise Map opens the Noise Map Editor. The Country Editor can also shade unselected countries and outline the selected country in the main 3D viewport.
