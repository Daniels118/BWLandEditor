Ground details and auxiliary terrain maps

The supplied source exposes several auxiliary terrain resources and maintenance tools rather than a single “ground details” brush.

Noise map

Tools → Noise Map Editor previews the current noise map and supports PNG import, PNG export and inversion. The Country Editor can overlay this map in its country preview.

Coastline bump map

Tools → Coastline Bump Map Editor provides the same import/export/invert workflow for the coastline bump resource.

Texture viewers

The Tools menu can open read-only viewers for the small bump texture and sky texture.

Shadows

Edit → Update Shadows recomputes landscape shadow information. Sculpt operations also update shadows for blocks changed by the stroke.

There is no separate ground-detail painting tool in the provided source tree; this page documents the terrain-detail resources that are currently implemented.
