Defining materials

The Materials Editor manages the texture resources used by landscape countries.

Open

Use Tools → Materials Editor. Materials are shown as texture thumbnails; unused materials are rendered with dimmed labels.

Operations

ActionDescription
Terrain material typeAssigns the selected material's terrain classification.
Import materialImports a PNG texture as a material resource.
Edit textureOpens the texture editor with live preview/apply/cancel behavior.
DuplicateClones the material.
Replace occurrencesReplaces all references to the selected material with another material.
ExportWrites the selected material to PNG.
RemoveAvailable only when the material can safely be removed.

The same window can be opened in selection mode by other tools (for example the Country Editor) to choose a material rather than edit the list.

This guide was completed from the supplied BWLandEditorGUI source code. UI wording can vary with the selected application language.
