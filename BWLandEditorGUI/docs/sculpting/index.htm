Editing the landscape

Landscape mode edits the LND terrain grid and its per-cell data. The left toolbar exposes the tools below.

ToolUse
Move selected cellsEnabled when terrain cells are selected; starts an interactive move/drop operation.
SculptRaise, lower, flatten, smooth or terrace terrain with configurable brushes.
OceanCreate/edit ocean bathymetry and coast transition.
LakeCreate/edit lake water with lake-specific sounds.
Country paintPaint a country using land/coast/slope/height filters.
Environment soundsPaint per-cell ambient sound classes.

Recommended order

  1. Define materials.
  2. Build countries from material mixes.
  3. Sculpt the shape of the land.
  4. Use water tools and country painting to refine surfaces.
  5. Add environment sounds and regenerate auxiliary detail maps as needed.
