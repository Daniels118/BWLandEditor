BWLandEditorGUI

Advanced tools and utility windows

These windows expose inspection, generation and lower-level resources used by the editor.

Land Generator

Tools → Land Generator generates procedural terrain from seed, width/height, altitude, frequency/octaves, coast noise, inland rise, coastal plain, mountains, ruggedness, lake attempts and island parameters. Biome rules can be ordered and filtered by altitude, slope, humidity, temperature and distance from water/lakes, and can assign countries and sounds. Generate, Randomize and Settle operations are available.

Block Inspector

Inspects a landscape block and its cells, including altitude, country, sound, flags and attributes. Cell backgrounds distinguish water, coastline, dry land and empty cells.

Model Viewer

Loads and previews available 3D model resources independently from object placement.

Edit History

The History window lists undoable edits newest-first. Selecting a history position moves the editor backward or forward to that point, providing a direct alternative to repeated Undo/Redo.

Console

The Console window receives application output. Automatic popup behavior is controlled by the Console Popup preference.

This guide was completed from the supplied BWLandEditorGUI source code. UI wording can vary with the selected application language.
