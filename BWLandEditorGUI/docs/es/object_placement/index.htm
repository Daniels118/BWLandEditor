BWLandEditorGUI

Colocación y edición de objetos

El modo Colocación de objetos edita las instrucciones LHX de creación de objetos mediante un flujo de trabajo 3D, manteniendo el script sincronizado.

Catálogo y arrastrar y soltar

Cambia a Colocación de objetos. La ventana Catálogo muestra vistas previas buscables de modelos cargados desde los recursos del juego. Arrastra un elemento del catálogo sobre terreno válido; los destinos no válidos o fuera de límites se resaltan y rechazan.

Valores automáticos al crear objetos

Las nuevas instrucciones reciben su tipo de objeto, posición, edad y un nuevo ID cuando es necesario. Según el comando, el editor también intenta deducir relaciones:

  • jugador desde la ciudad más cercana;
  • ciudad desde una ciudad próxima, cuando el comando admite esa asociación;
  • rebaño desde un rebaño cercano cuando el punto está dentro de su radio;
  • bosque desde un bosque cercano;
  • hogar del aldeano desde la vivienda libre compatible más cercana.

Selección y movimiento de objetos

La herramienta Puntero selecciona objetos. Ctrl-clic alterna la selección de un objeto. Arrastrar mueve los objetos seleccionados como grupo; iniciar el arrastre manteniendo Ctrl duplica primero las instrucciones seleccionadas.

La herramienta de selección poligonal admite Nueva/Añadir/Restar/Intersecar. Un clic derecho sobre los objetos abre comandos para refinar/ampliar la selección, seleccionar padres/hermanos/hijos/descendientes, mostrar un objeto en la Vista de árbol LHX, copiar, cortar o eliminar.

Propiedades del objeto

La ventana Propiedades del objeto se genera a partir del esquema de argumentos del comando seleccionado. Admite campos de coordenadas, números flotantes/enteros, booleanos, cadenas y opciones enumeradas. Las restricciones de posición/rotación/escala/edad se adaptan al comando. Los ID duplicados se marcan.

Hay paneles especializados para creencia de ciudad, límites de creencia y mejoras de deseo; las viviendas muestran recuentos de aldeanos/niños y flags relevantes como planificado/muerto/inhabitable cuando son compatibles.

Vista de árbol LHX

El árbol ofrece una jerarquía buscable de objetos LHX renderizados y sigue la selección de la vista 3D. Los enlaces padre/hijo corresponden a las relaciones mostradas por la superposición Enlaces.

Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
