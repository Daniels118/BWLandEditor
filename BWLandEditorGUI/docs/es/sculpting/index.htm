Edición del terreno

El modo terreno edita la cuadrícula LND y los datos de cada celda. La barra de herramientas izquierda ofrece las herramientas siguientes.

HerramientaUso
Mover celdas seleccionadasSe habilita cuando hay celdas del terreno seleccionadas; inicia una operación interactiva de mover/soltar.
EsculpirEleva, baja, aplana, suaviza o crea terrazas con pinceles configurables.
OcéanoCrea/edita la batimetría oceánica y la transición de costa.
LagoCrea/edita agua de lago con sonidos específicos.
Pintar regionesPinta una región usando filtros de tierra/costa/pendiente/altura.
Sonidos ambientalesPinta clases de sonido ambiental por celda.

Orden recomendado

  1. Define los materiales.
  2. Construye las regiones a partir de mezclas de materiales.
  3. Esculpe la forma del terreno.
  4. Usa las herramientas de agua y el pintado de regiones para refinar las superficies.
  5. Añade sonidos ambientales y regenera los mapas auxiliares de detalle cuando sea necesario.
Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
