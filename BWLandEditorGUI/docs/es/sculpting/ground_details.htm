Detalles del terreno y mapas auxiliares

El código fuente proporcionado expone varios recursos auxiliares del terreno y herramientas de mantenimiento en lugar de un único pincel de “detalles del terreno”.

Noise map

Herramientas → Editor de noise map muestra la noise map actual y permite importar PNG, exportar PNG e invertir. El Editor de regiones puede superponer este mapa en la vista previa de la región.

Bump map de costa

Herramientas → Editor de bump map de costa ofrece el mismo flujo de importación/exportación/inversión para el recurso bump de costa.

Visores de texturas

El menú Herramientas puede abrir visores de solo lectura para la small bump texture y la textura del cielo.

Sombras

Editar → Actualizar sombras recalcula la información de sombras del terreno. Las operaciones de esculpido también actualizan las sombras de los bloques modificados por el trazo.

No existe una herramienta separada para pintar detalles del terreno en el código fuente proporcionado; esta página documenta los recursos de detalle actualmente implementados.
Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
