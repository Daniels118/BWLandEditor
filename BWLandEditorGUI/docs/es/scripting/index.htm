Scripts LHX

La ventana Script LHX es un editor orientado a líneas respaldado directamente por la lista actual de instrucciones LHX. Editar una instrucción actualiza la representación 3D del objeto y seleccionar un objeto renderizado puede revelar su línea de script.

Edición

  • Cada línea se analiza como una instrucción LHX. Los comandos válidos, comentarios e instrucciones no válidas usan estilos distintos.
  • Enter al inicio/final de una línea inserta una nueva instrucción antes/después.
  • Eliminar una línea vacía con Retroceso o Supr elimina esa instrucción.
  • Las flechas pueden moverse entre filas adyacentes en los límites de línea; Re Pág/Av Pág se desplazan por páginas visibles.
  • Ctrl+Inicio/Fin va a la primera/última instrucción.
  • Ctrl+Espacio abre el completado contextual de comandos/argumentos.

Búsqueda

El campo de búsqueda encuentra texto en el script con controles anterior/siguiente y reanuda la búsqueda desde el principio/final cuando corresponde.

Referencia de posición

Al pasar el cursor sobre un comando que tiene posición se muestra un marcador temporal en la vista 3D. La selección se sincroniza en ambos sentidos entre el script y los objetos renderizados.

Atributos del mapa

Editar → Configuración del mapa abre un editor estructurado de propiedades de mapa a nivel de script. El código fuente proporcionado incluye:

  • ajustes generales como versión, número de mapa/ruta del terreno, multiplicadores de influencia de ciudad/jugador, duración del día y proporciones día/noche/amanecer-atardecer;
  • configuración de jugadores controlados por el ordenador;
  • propiedades de equilibrio;
  • probabilidades de milagros firefly;
  • ajustes de escaramuza, incluido número de jugadores y mensajes de inicio/juego.

Ayuda de cámara

El modo Script abre Información de cámara, que expone la posición actual y el punto de mira y puede generar/copiar comandos set/move de cámara para usarlos en scripts.

Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
