Flujo de trabajo rápido

  1. Abre un proyecto .lnd o LHX .txt existente, o crea uno nuevo.
  2. Define o importa materiales y regiones.
  3. Da forma al terreno con las herramientas de esculpido/océano/lago y pinta regiones o sonidos ambientales.
  4. Cambia a Colocación de objetos para añadir y configurar objetos LHX.
  5. Usa la ventana Script LHX para editar instrucciones y después guarda tanto el terreno como el script.
Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
