BWLandEditorGUI

Proyectos, archivos, importación/exportación y recuperación

El editor trata el terreno (.lnd) y el script de inicialización LHX (.txt) como componentes relacionados del mismo proyecto y guarda cada uno cuando contiene cambios sin guardar.

Abrir y guardar

  • Abrir acepta archivos .lnd y .txt. Al abrir un script LHX puede cargarse automáticamente el terreno al que hace referencia si la carpeta del juego está configurada.
  • Guardar guarda ambos componentes modificados. Guardar mapa como y Guardar LHX como permiten elegir destinos independientes.
  • Al abrir otro proyecto o salir se pregunta qué hacer con los cambios pendientes.
  • La ventana inicial muestra archivos .lnd/.txt recientes; el número máximo es configurable.

Importar mapa

Archivo → Importar mapa importa bloques desde otro terreno sin sustituir el actual. Las regiones usadas por los datos importados se asignan a regiones de destino. El diálogo permite correspondencia automática, decisiones manuales de asignación/importación, recordar asociaciones y borrar decisiones almacenadas.

Después de la asignación, el terreno importado aparece como vista previa en la vista 3D. Muévelo a la posición deseada y confirma con Enter; Esc cancela. Puede solicitarse alineación con la cuadrícula.

Importar height map

Archivo → Importar height map lee un PNG, lo convierte en terreno y después permite posicionar el resultado. Antes de importar puedes:

  • girar en sentido horario/antihorario o reflejar horizontal/verticalmente ;
  • elegir las regiones normal, acantilado y costa, incluidos los botones para tomarlas del mapa;
  • establecer la pendiente del acantilado, sonido ambiental y alineación con la cuadrícula;
  • usar el asistente de configuración de regiones con un clic.

Exportar

Exportar height map guarda el terreno actual como PNG. El botón de captura guarda la vista 3D renderizada.

Guardado automático y recuperación

Existen dos protecciones independientes. Guardado automático escribe periódicamente los archivos de trabajo; Recuperación automática crea copias temporales de recuperación de los cambios no guardados del terreno/LHX.

Tras una interrupción anómala, las entradas de recuperación aparecen en la ventana inicial y pueden volver a abrirse o eliminarse. Los archivos de recuperación se borran automáticamente después de guardar normalmente el documento correspondiente.

Esta guía se completó a partir del código fuente de BWLandEditorGUI proporcionado. Los textos de la interfaz pueden variar según el idioma seleccionado en la aplicación.
