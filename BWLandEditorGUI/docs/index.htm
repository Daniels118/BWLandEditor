Quick workflow

  1. Open an existing .lnd or LHX .txt project, or create a new project.
  2. Define or import materials and countries.
  3. Shape the terrain with the sculpt/ocean/lake tools and paint countries or environment sounds.
  4. Switch to Object Placement to add and configure LHX objects.
  5. Use the LHX Script window for statement-level editing, then save both landscape and script.
