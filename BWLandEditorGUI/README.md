# Black & White Land Editor

A tool for creating and editing custom maps for the *Black & White* video game.

## Description

This project allows users to create or modify maps for *Black & White*, providing dedicated tools for terrain editing, object placement, and scripting support.

## Features

- Create new maps or edit existing ones
- Landscape editing
    - Import textures
    - Create/edit countries
    - Sculpt the terrain
    - Set environment sounds
- Pick coordinates

## Features on the roadmap

- Object and entity management
- Scripting assistant
